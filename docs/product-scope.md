# 影间首版产品范围

## 产品定位

“影间”是一款结合皮影文化展示、服饰纹样临摹与照片海报创作的 Android APP。它不是通用画图软件，核心区别是用户围绕皮影展品、影人和纹样完成具有明确文化语境的创作。

## 核心流程

```text
浏览皮影展馆
→ 查看角色、起源和纹样寓意
→ 选择服饰纹样进行临摹
→ 拍照或导入背景
→ 加入透明皮影人物、绘画和题字
→ 调整位置、大小、角度和层级
→ 保存可编辑草稿
→ 导出并分享海报
```

## 底部入口

- 展馆：皮影条目、角色、纹样、搜索与收藏。
- 创作：纹样临摹、拍照搭台与海报合成。
- 作品：本地草稿、导出作品和云端作品。

## 首版数量

- 6—8 个皮影展示条目。
- 4 张纹样临摹底图。
- 2 套海报模板。
- 2—4 个透明皮影人物素材。

## 首版不做

- 实时 AR 追踪。
- 皮影骨骼动画。
- 视频录制与导出。
- 社区评论和即时聊天。
