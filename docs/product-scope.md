# 影间首版产品范围

## 产品定位

“影间”是一款结合皮影文化展示、服饰纹样临摹与照片海报创作的 Android APP。它不是通用画图软件，核心区别是用户围绕皮影展品、影人和纹样完成具有明确文化语境的创作。

## 核心流程

```text
浏览皮影展馆
→ 查看角色、起源和纹样寓意
→ 选择服饰纹样进行临摹
→ 拍照或导入背景
→ 加入透明皮影人物、绘画和题字
→ 调整位置、大小、角度和层级
→ 保存可编辑草稿
→ 导出并分享海报
```

## 底部入口

- 展馆：皮影条目、角色、纹样、搜索与收藏。
- 创作：纹样临摹、拍照搭台与海报合成。
- 作品：本地草稿、导出作品和云端作品。

## 相机功能定位

相机用于采集海报创作的真实场景背景。用户可以拍摄校园、庭院、建筑或室内空间，把照片当作皮影“舞台”，随后叠加透明皮影人物、自己临摹的纹样、题字和边框。拍照后需要完成照片方向校正、简单裁切、尺寸压缩和应用内持久化，再进入合成画布继续编辑。

因此，相机的演示闭环是：

```text
拍摄或选择照片 → 处理并保存背景 → 加入皮影素材 → 手势调整 → 导出海报
```

它不是单纯的系统相机调用，也不承担实时 AR、识别或视频功能。

## 首版数量

- 6—8 个皮影展示条目。
- 4 张纹样临摹底图。
- 2 套海报模板。
- 2—4 个透明皮影人物素材。

## 首版不做

- 实时 AR 追踪。
- 皮影骨骼动画。
- 视频录制与导出。
- 社区评论和即时聊天。
